# RouterA Dynamic NAT Lab

A GitHub-ready beginner lab for configuring dynamic NAT on Cisco RouterA.

## Folder guide
1. `1-configs/` — router configuration and line-by-line explanation
2. `2-topology/` — topology image and addressing notes
3. `3-verification/` — verification commands and troubleshooting checklist
4. `4-purpose-and-tasks/` — scenario, requirements, design choices, and learning outcomes

Start with `4-purpose-and-tasks/Purpose-and-Tasks.md`, apply `1-configs/RouterA-Dynamic-NAT.txt`, then follow the verification steps.

**Reminder:** This is a NAT-focused lab. ISP addressing, default routing, and return routing are not specified in the original task and must be added for a complete end-to-end test.
